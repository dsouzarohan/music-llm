# 2025-12-29

- Added the model changes
    - GELU instead of ReLU
    - Added GPT-2 initialisation as we are at 24 layers
- Model reached a new validation loss `val_loss 3.7180  ppl 41` - this is now the lowest validation loss we’ve had since the model changes
- However, the ideal loss we’re looking at is still around `2.3 (ppl 10)` which is actually a long way away. There are three possible reasons as to why our loss is stuck around here
    - Data - the model (186M parameters with 24 layers) right now is being trained on \~42M tokens but need \~3.7B. We cannot generate 3 billion tokens from 42 million just by "training longer." We need **Data Augmentation** on an industrial scale.
        - We’re already using data augmentation but need to scale it up a lot! **The Augmentation Recipe:**
            1. **Pitch Augmentation (x12):** Transpose every song into every possible key (-5 to +6 semitones). Guitar riffs sound musically valid in any key.
            2. **Velocity scaling (x3):** Create "Loud", "Medium", and "Soft" versions of every song.
            3. **Time Stretching (x3):** Speed up/slow down the tempo by 5-10%
        - We might very well need to get in more MIDI data, as we were ideating earlier
            - More MIDI files to represent music theory to give the model an idea of how music is structured, and then perform further training on actual songs
            - [Free Midi - Best Free High Quality Midi Site](https://freemidi.org/) itself has a lot of data
                - Might have to work on some web scrapping here to download all and then tokenise all
            - [chatgpt.com](https://chatgpt.com/g/g-p-67fba7907c408191876a192f8df9495e-prj-music-transformer/c/6929c488-66a4-8320-886a-69e9bb80f4e1) thread includes ideas to synthetically generate data as well as get MIDI files
    - Tokenisation 
        - The current tokenisation config is "safe" but likely loses the expressive "human" feel of guitar performance.
        - [How to Make Your MIDI Guitar Sound Realistic](https://www.youtube.com/watch?v=3D9yIFxtue4)
