# 2025-09-08

Back after a while, but this time with a lot of ideas and knowledge

After going through Karpathy’s nanoGPT tutorial, I’ve gotten a good idea of how to go about this project

Since the last time, what I had was a few isolated GnR electric guitar tracks

Read a little about MidiTok’s internals - it also includes tokenizer algorithms to train the tokenizer given any MIDI dump - what I did is I trained the tokenizer on that dump to build up a vocabulary size of 8000 (compared to the base 441) which might seem a lot but the good thing with BPE is it creates new token representations from the data given to it so in the long run the overall context window/block size/time can be smaller

I also used its inbuilt method to tokenize all the MIDI files, so for 33 input tracks, it has created 34 JSON files
