### Possible Next steps (from GPT, need to isolate a few)

1. **Monophony filter (per track, pre-tokenize)**
    - Compute **simultaneous-note count** per tick/bar.
    - Keep segments where `avg_polyphony ≤ 1.2` and `max_polyphony ≤ 2`.
    - Drop bars with long sustained triads (rhythm).
        *Effect:* the model mostly sees single-note lines.
2. **Range/density heuristics**
    - Keep tracks with **wide pitch range** (≥ 12–15 semitones) and **note density** \~ moderate (neither strummy walls nor sparse pads).
    - Solos = bigger range + occasional rests.
3. **Program/instrument hints**
    - Prefer GM programs 30–31 (**Overdriven/Distortion Guitar**) for lead; deprioritize 27–29 if they look like comping.
    - If multiple guitar tracks in a MIDI, pick the one with **more pitch-bend / aftertouch** events (often the lead).
4. **Solo segment slicing**
    - Many MIDIs label sections (or you can detect with **note density peaks** around the solo). Slice only those bars.
    - Keep 8–24 bars centered around the detected peak density change.
5. **Tokenization config for leads**
    - Try `use_chords=False` (so the vocab doesn’t explicitly model chord tokens).
    - Consider `use_programs=False` once you’ve filtered to guitar (reduces vocab/variance).

### Training & sampling tricks that bias to single-note lines

1. **Style/role tag (simple conditioning)**
    - Prepend a token like `<ROLE=LEAD>` for your lead slices (and `<ROLE=RHYTHM>` for rhythm, if you keep any).
    - At generation, start with `<ROLE=LEAD>` + a short prime.
2. **Prime smartly**
    - Seed with 1–2 bars of **actual lead** from a held-out GnR solo before sampling. Huge boost in phrasing.
3. **Sampling settings**
    - Lower **temperature** to `0.8–0.95`.
    - Use **top-k = 30–60** (or top-p ≈ 0.9).
    - Add **repetition penalty** (e.g., 1.1–1.2) to stop stuck riffs.
4. **Soft polyphony guard at decode**
    - When detokenizing, if multiple Note-On events land at the same time step, **keep only the highest-velocity (or top pitch)** for a lead run.
    - Or push close-onset notes into **staggered micro-arpeggios** (tiny TimeShift) so they read as fast licks rather than block chords.
